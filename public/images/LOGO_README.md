# School Logo Instructions

To add your school logo to the Space Tracker:

1. Add your PVPV/Rawlings Elementary Sea Turtle logo to this folder
2. Name the file: `NEW-LOGO.png` (or update the filename in `SeaTurtleSpaceTrackerBranded.jsx`)
3. Recommended size: 256x256 pixels or larger (will be displayed at 64x64)
4. Format: PNG with transparent background preferred

The logo will appear in the header next to the "Sea Turtle Space Tracker" title.

If you don't have the logo file, the app will still work perfectly - it will simply hide the logo space.
